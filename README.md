# Tablero de ventas TACOMA

Página estática para GitHub Pages (ventas.tacoma-maderas.com.ar).
Se arrastra el CSV de facturas exportado de Zoho Books; los datos se procesan y guardan
solo en el navegador (IndexedDB). Este repositorio contiene únicamente el código: no subir
CSV ni respaldos (el .gitignore los bloquea).
